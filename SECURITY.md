# Security policy

## Supported versions

Only the latest release on the `main` branch is supported. Fixes are released as a
new patch version (for example 1.0.1).

## Reporting a vulnerability

Please do not report security problems in a public issue.

Use **Security → Report a vulnerability** on this repository to send a private report.
Describe the problem, the steps to reproduce it and, if you know it, the affected file
or page. You will get a reply as soon as possible, and the fix will be credited to you
in the changelog unless you prefer otherwise.

The site is static: it has no server, accounts or database. Notes and papers open from Google Drive, videos from YouTube (privacy-enhanced mode) and element data from PubChem.
